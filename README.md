# Netflix EDA

Exploratory Data Analysis of the Netflix titles dataset using Python and Pandas.

## What this project covers

- Data loading and dataset understanding
- Missing-value and duplicate analysis
- Data cleaning and datetime conversion
- Univariate analysis
- Bivariate analysis
- Distribution and outlier analysis using IQR
- Correlation analysis
- Business insights and recommendations

## Tools

Python · Pandas · NumPy · Matplotlib · Seaborn

## Notebook

Open [Netflix_EDA.ipynb](./Netflix_EDA.ipynb) to view the complete analysis.

## Dataset

The notebook expects the Netflix titles dataset as **netflix_titles.csv** in the repository root.
